# Kairos v1.1.15

## Highlights

- Fixed launch-at-login on macOS and Linux — toggle now takes effect in the current session, no logout required.
- Desktop frontend now refreshes every timeframe automatically when the window regains focus.
- New landing-page section showcasing Kairos features, plus a full mobile/tablet responsive pass.

## Desktop App

- **Window focus → live refresh.** When the Kairos window regains focus or becomes visible, every registered data source (overview, analytics, sessions, calendar, settings) refetches. Throttled at 2s to coalesce focus+visibility duplicates.
- VS Code extension status is re-probed on focus alongside the data refresh.

## Backend

- **macOS autostart actually registers with `launchd`.** `ensureMacLaunchAgent` now runs `launchctl bootout` (best-effort) and `launchctl bootstrap gui/<uid> <plist>` after writing the file, so enabling the setting takes effect immediately instead of waiting for the next login.
- **Linux autostart now writes a spec-compliant `.desktop` file.** `Exec=` is double-quoted and reserved characters (`\`, `"`, `` ` ``, `$`) are backslash-escaped per XDG Desktop Entry §5 — paths containing spaces no longer silently fail on GNOME/KDE.
- **AppImage / Snap paths persisted correctly.** The Linux autostart entry now prefers `$APPIMAGE` and `$SNAP_INSTANCE_NAME` over `os.Executable()`, so entries written from inside an AppImage no longer point at ephemeral `/tmp/.mount_*` paths that vanish on reboot.
- `--login-launch` is now appended to Linux `Exec=` when `loginLaunchMode` is `menubar`, matching the macOS behavior.

## Landing Site

- New `FeaturesOfKairos` section listing the six core capabilities (local-first SQLite, sessionization, editor-aware tracking, privacy controls, multi-machine identity, flexible time ranges).
- Mobile/tablet responsive pass across Nav (new hamburger drawer), Hero, Problem, HowItWorks, FeatureGrid, Privacy, Stats, DownloadCTA, Footer. Desktop (xl+) rendering unchanged.
- Removed Windows from the download CTA (Kairos currently ships macOS + Linux only).
- Fixed broken repo links — GitHub, Releases, Issues, Docs now resolve. Dropped the VS Code Marketplace footer link until the extension is published.
- Switched display font to Montserrat; body and mono use DM Sans.

## Tests

- New Go tests for XDG Exec escaping, the menubar `--login-launch` flag, and `$APPIMAGE` / `$SNAP_INSTANCE_NAME` precedence.
- Full suite green (176 tests).
