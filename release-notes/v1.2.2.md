# Kairos v1.2.2

## What's New

- Kairos now shows a compact **Syncing** indicator when existing dashboard data refreshes in the background.
- Loading placeholders have a softer shimmer with better contrast in light and dark themes.
- Screens feel steadier when switching ranges or filters because cached content is kept visible whenever possible while fresh data loads.
- Navigation pills and segmented controls animate more smoothly across the desktop app.
- Fresh editor setup is cleaner with placeholder text removed from the bundled plugin.

## Desktop App

- Background updates are easier to notice without interrupting the current view.
- Loading states are more polished across overview, analytics, sessions, calendar, and settings screens.
- Theme colors for loading feedback now adapt cleanly between light and dark mode.
