# Kairos v1.1.11

## Highlights

- Preloaded known dashboard, analytics, sessions, calendar, and settings data so page switches can render from cache immediately.
- Added all-time support to overview, analytics, and sessions ranges while avoiding unsupported comparison data for all-time analytics.
- Fixed initial page chart state so charts mount with the selected range instead of briefly animating from a fallback weekly range.

## Desktop App

- Warmed known preset ranges at launch and when the current page is ready.
- Cached analytics source data by range so project, language, and machine filter changes can reuse already fetched session data.
- Delayed route mounting until bootstrap data is ready to prevent first-render range mismatches.
- Restored saved overview, analytics, sessions, and calendar selections before first data resource keys are created.
