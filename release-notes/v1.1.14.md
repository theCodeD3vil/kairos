# Kairos v1.1.14

## Highlights

- Added a "Last 90 days" preset to every time-range selector across Overview, Analytics, and Sessions pages.
- Reworked Analytics into a cockpit-style Summary tab with an opt-in Advanced Analytics tab for derived scores.
- Moved analytics filters into the sticky tab header for a single fixed control surface while scrolling.
- Replaced analytics jargon with concrete metric labels and added benchmarks/tests for event-activity KPIs.

## Desktop App

- Extended `OverviewRange` to include `last-90-days`; preset list order is now `1D · 7D · 1M · 90D · All`.
- New `Analytics` settings tab with a toggle (disabled by default) that gates the Advanced Analytics scores tab.
- `VercelTabs` now auto-scrolls the nearest scrollable ancestor to top on tab switch, so tab changes land at the section header.
- Project- and language-share charts accept dynamic item limits and surface sparkline data.

## Backend

- `views/service.go` resolves `last-90-days` (end = today, start = end − 89 days).
- `settings/validation.go` whitelists `last-90-days` for `DefaultDateRange`.
