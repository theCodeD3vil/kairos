# Kairos v1.1.12

## Highlights

- Added merge-only activity import for Kairos export files from other machines or app instances.
- Strengthened activity export files with version metadata, machine metadata, summaries, and content digest validation.
- Added an import preview flow that shows new, duplicate, conflicting, and invalid activity before merging.

## Desktop App

- Preserves imported project names, languages, and exact file paths without runtime filtering.
- Merges new raw events as the source of truth and rebuilds affected sessions after import.
- Keeps legacy session-only imports available as a fallback for older export files.
